# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.1] - 2026-11-21

### Added
- Page cache with per-path exclusions, TTL and a manual purge (Caching, media optimization and database cleanup in one plugin)
- HTML/CSS/JS optimization, WebP and AVIF generation
- Database cleanup, table optimization and local `.sql.gz` backups
- Sitemap index, Open Graph, Twitter cards, JSON-LD
- 404 log with one-click redirects

### Changed
- Settings screen regrouped into nine tabs

### Fixed
- Admin screen reproduces correctly on non-UTF-8 databases
